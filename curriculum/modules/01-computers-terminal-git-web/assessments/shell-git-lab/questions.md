## Multiple choice (1 point each)

**1.** What command creates a new directory named "projects" in the current working directory?

a) `mkdir projects`  
b) `create projects`  
c) `newdir projects`  
d) `cd projects`

**2.** In Git, what is the staging area?

a) A remote repository where code is deployed  
b) A temporary area where changes are collected before committing  
c) A list of all branches in the repository  
d) The directory where compiled binaries are stored

**3.** What does the `git status` command show?

a) The commit history of the current branch  
b) The differences between two commits  
c) The current state of the working directory and staging area  
d) The remote repository's URL

**4.** Which Git command creates a new branch named "feature-login"?

a) `git branch feature-login`  
b) `git create feature-login`  
c) `git new branch feature-login`  
d) `git checkout feature-login`

**5.** What is the exit code of a Go program that completes successfully?

a) -1  
b) 0  
c) 1  
d) 2

**6.** What is a DNS resolver responsible for?

a) Encrypting HTTP traffic  
b) Converting domain names to IP addresses  
c) Routing packets between networks  
d) Managing TCP connections

**7.** Which HTTP method is typically used to retrieve data from a server?

a) POST  
b) PUT  
c) GET  
d) DELETE

**8.** What does HTTP status code 404 indicate?

a) Internal server error  
b) Unauthorized  
c) Not Found  
d) OK

**9.** In Git, what is the difference between `git merge` and `git rebase`?

a) Merge creates a new commit with two parents; rebase rewrites history by replaying commits  
b) Merge is for branches; rebase is for tags  
c) Merge works locally; rebase works remotely  
d) There is no difference

**10.** What happens when a shell command is piped using `|`?

a) The output of the first command is saved to a file  
b) The output of the first command becomes the input of the second command  
c) Both commands run in parallel  
d) The first command's errors are suppressed
