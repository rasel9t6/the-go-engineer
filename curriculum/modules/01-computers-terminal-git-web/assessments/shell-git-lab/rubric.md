# Shell + Git Lab — Rubric

## Criteria

### 1. Shell fluency (30%)

| Level | Score | Description |
|-------|-------|-------------|
| Excellent | 5 | Correctly navigates filesystem, creates directory tree, creates files, uses pipes and redirects. Explains what each command does. |
| Proficient | 3 | Most commands correct; minor errors in path resolution or syntax. Can explain most commands. |
| Developing | 1 | Struggles with basic navigation and file operations. Cannot explain command behavior. |
| Not attempted | 0 | No shell work demonstrated. |

### 2. Git workflow (35%)

| Level | Score | Description |
|-------|-------|-------------|
| Excellent | 5 | Complete Git workflow demonstrated: init, add, commit, branch, merge, conflict resolution. Meaningful commit messages. Clean history shown by `git log --oneline --graph`. |
| Proficient | 3 | Basic workflow works (init, add, commit) but branching or merging has errors. Commit messages are minimal. |
| Developing | 1 | Can initialize a repo and make commits but cannot branch or merge. |
| Not attempted | 0 | No Git work demonstrated. |

### 3. Proof / verification output (20%)

| Level | Score | Description |
|-------|-------|-------------|
| Excellent | 5 | All 14 verification checks pass. Screenshot or copy of terminal output provided showing the pass/fail summary. |
| Proficient | 3 | Most checks pass (10-13). Some checks fail due to minor issues. |
| Developing | 1 | Fewer than 10 checks pass. Significant gaps in the workflow. |
| Not attempted | 0 | No verification output provided. |

### 4. Conceptual understanding (15%)

| Level | Score | Description |
|-------|-------|-------------|
| Excellent | 5 | Clearly explains the three-state model (working directory / staging / history), why Git uses SHA-1 hashes, and what happens during a merge of divergent branches. |
| Proficient | 3 | Can explain most concepts but has gaps in deeper understanding (e.g., cannot explain why SHA-1 is used). |
| Developing | 1 | Can name concepts but cannot explain how they work or why they matter. |
| Not attempted | 0 | No explanation provided. |

## Scoring guide

| Total points | Grade |
|--------------|-------|
| 18-20 | Exceeds expectations |
| 14-17 | Meets expectations |
| 8-13 | Needs improvement |
| 0-7 | Incomplete — retake recommended |
