# Module 02 — Go Setup and Tooling

**Goal**: Make the Go toolchain normal from day one.

**Phase**: Tooling

**Cognitive load**: Low

**Pacing**: Gentle

## Description

This module introduces the Go toolchain — the commands and tools you will use every day as a Go developer. You will install Go, write your first program, and learn how to compile, run, test, format, and analyze Go code. By the end of this module, you will have a fully verified Go development environment and the confidence to use the toolchain without assistance.

## Prerequisites

- Module 01 — Computers, Terminal, Git, and the Web

## What you will be able to do

- Install and verify Go on any platform
- Write, compile, run, and test Go programs
- Format code with `gofmt` and detect bugs with `go vet`
- Read documentation with `go doc` and use `gopls` in your editor
- Read and fix compiler errors, runtime panics, and test failures
- Understand `go.mod`, module paths, and dependency management
- Run a complete tooling checklist to verify your environment
