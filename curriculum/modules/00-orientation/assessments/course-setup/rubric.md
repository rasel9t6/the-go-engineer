# Rubric

| Category | Weight | Pass Criteria |
|---|---|---|
| Go environment | 20% | `go version` output matches expected; editor has Go support |
| Repository setup | 25% | Fork and clone commands are correct; `git remote -v` shows the fork |
| Course project | 25% | Verification project runs and tests pass; learner can describe what the starter checks |
| Reflection | 30% | Honest, specific answers showing the learner engaged with the setup process |

**Passing standard:** 70% or higher across all categories, with no category below 50%.

**Self-grade before submitting.** Compare your answers with `answer-key.md`.
